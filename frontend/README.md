# Mural de Avisos [3ºDS]
Mural de Avisos feito em prol da sala 3ºB do curso técnico de Desenvolvimento de Sistemas
com o objetivo de deixar exposto atividades pendentes com prazos próximos ou atividades
do AVA que foram solicitados a realização para facilitar a sala à deixar suas
atividades em dia.
